# NIGHTFALL — 저격수 퍼즐

네온 사이버펑크 UI의 HTML5 Canvas 저격 퍼즐 프로토타입입니다. 최신 v4를 기준으로 하며 8개 스테이지를 포함합니다.

## 실행

저장소를 내려받은 후 `index.html`을 브라우저로 엽니다. 별도 설치나 빌드가 필요 없습니다. Pretendard 폰트는 CDN에서 불러오며, 오프라인에서는 기본 글꼴로 대체됩니다.

## 조작

- 게임 필드에서 위로 드래그하여 조준하고 놓으면 발사합니다.
- 제한된 탄환으로 모든 타겟을 제거하세요.
- `R`: 스테이지 재시작 / `Esc`: 조준 취소 및 가이드 닫기
- 하단 메뉴에서 스테이지 선택, 브리핑, 음소거를 사용할 수 있습니다.

## 구성

- `index.html`: UI, 스테이지 데이터, 게임 로직
- `assets/`: 캐릭터 이미지와 사운드
